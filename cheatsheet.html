Looking around

pwdwhere am I?
ls · ls -l · ls -awhat is in here?
cd folder · cd .. · cd ~go in · go up · go home
treedraw the whole folder shape
cat fileshow what is inside a file
grep word filefind lines containing a word
find . -name "*.py"search for files by name

Making and breaking

mkdir name · mkdir -p a/b/cnew folder · and every folder on the way
touch file.txtnew empty file
echo "hi" > filewrite into a file (replaces it!)
echo "hi" >> fileadd to the end
nano fileopen the editor
cp a b · mv a bcopy · move or rename
rm file · rm -r folderno undo. read it twice

Switching ROS 2 on

source /opt/ros/jazzy/setup.bashin every new terminal
source install/setup.bashafter every colcon build
ros2 doctoris my setup healthy?
printenv ROS_DISTROwhich ROS 2 am I using?

Nodes — the little programs

ros2 run <pkg> <exe>start one node
ros2 node listwhat is running?
ros2 node info /nameits full job description
jobs · kill <node> · kill allacademy extras (real life: Ctrl+C)

Topics — the robot radio

ros2 topic list -tevery channel, with its type
ros2 topic echo /chatterlisten in (Ctrl+C to stop)
ros2 topic info /chatter -vwho talks, who listens, what QoS
ros2 topic hz /chattermessages per second
ros2 topic pub --once /t <type> "{...}"send one message by hand
ros2 interface show <type>what shape is this message?

Services, parameters, actions

ros2 service list -twhat can I ask for?
ros2 service call /srv <type> "{...}"ask once, get one answer
ros2 param lista node's settings
ros2 param get /node keyread a setting
ros2 param set /node key valuechange it while it runs
ros2 action send_goal /a <type> "{...}" --feedbacka long job, with progress

Building your own

mkdir -p ~/ros2_ws/srcmake a workspace
ros2 pkg create my_pkg --build-type ament_pythonname first, or --dependencies eats it
colcon buildfrom the workspace root, not src
colcon build --packages-select my_pkgjust one package
ros2 launch my_pkg my_launch.pystart everything at once

Renaming things at startup

--ros-args -r __node:=newnamerun the same node twice
--ros-args -r __ns:=/robot1a whole robot in its own namespace
--ros-args -r /old:=/newpoint a topic somewhere else
--ros-args -p key:=valueset a parameter at startup

Recording

ros2 bag record /topic · -arecord one topic · everything
ros2 bag info <folder>what is in this recording?
ros2 bag play <folder>live through it again

When nothing works, ask these four questions in order: 1. Is it running? ros2 node list — 2. Is anyone shouting? ros2 topic info /t (is Publisher count 0?) — 3. Are the names exactly the same? ros2 topic list (/cmd_vel ≠ /turtle1/cmd_vel) — 4. Is it arriving? ros2 topic echo /t. Still silent with a publisher present? Compare QoS with ros2 topic info /t -v: a RELIABLE subscriber refuses a BEST_EFFORT publisher, and says nothing about it.
